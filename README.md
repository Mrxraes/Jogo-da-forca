--> Este é um projeto simples com python do jogo muito conhecido: jogo da forca.

--> O usuário deve confirmar se deseja jogar, se a resposta for positiva, pergunta-se o nome 
do mesmo e incia-se o jogo.

--> O jogo é simples --> acertar a palavra antes de a forca se formar.

--> Se o usuario vencer, a sua pontuação é guarda no arquivo "usuarios.txt", junto de seu nome.

FOI UTILIZADO:

- Condicionais (if, else);
- Laços de repetição;
- Abertura e fechamento de arquivos.txt (modos e métodos)
- Funções
- Biblioteca externa (para "sortear" uma palavra aleatório existente em "palavras.txt")
- Arrays como "banco de dados".
